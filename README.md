# 📊 Student Performance Predictor

A simple **machine learning regression project** that predicts student exam scores based on:

- Study hours  
- Sleep duration  
- Attendance percentage  

Built using **Python, Pandas, Scikit-learn, and Matplotlib** to demonstrate the complete **ML workflow from data to prediction and visualization**.

---

## 🚀 Features

- 📂 CSV dataset loading and preprocessing  
- 🤖 Linear Regression model training  
- 📉 Model evaluation using:
  - Mean Absolute Error (MAE)
  - R² Score  
- 🔮 Predicts score for a **new student input**  
- 📊 Visualizes **Actual vs Predicted scores**  

---

## 🛠️ Tech Stack

- **Language:** Python  
- **Libraries:**  
  - Pandas  
  - Scikit-learn  
  - Matplotlib
